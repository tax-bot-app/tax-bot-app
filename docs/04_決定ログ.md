# 決定ログ

## 2026-07-23 無料回答後の有料版案内と信頼情報を追加

- 無料体験の直前に、野口税理士の顔写真、資格・肩書き、法人税務・税務調査対応の実務経験を表示する。
- 無料回答の直後に、その相談を有料版でどこまで具体化できるか4項目で示す。
- 回答後CTAは「この相談の続きを整理する」とし、プラン選択へつなぐ。
- 保存された無料体験回数だけでは案内を表示せず、その画面で回答が正常に表示された場合に限って表示する。

## 2026-07-23 出張日当の相談例・回答例を追加

- トップの無料体験直後に、出張日当2万円を題材とした相談例・回答例を常時表示する。
- 「設定できる可能性」を入口にしつつ、旅費規程だけでは非課税が確定せず、会社規模、役員・従業員間のバランス、出張実態等の確認が必要であることを示す。
- CTAは「自社の場合を相談してみる」とし、無料体験の入力欄へ戻してフォーカスする。

## 2026-07-23 新規登録後の未契約導線を修正

- プラン指定なしのメール認証後は、チャットではなくトップのプラン選択へ遷移する。
- freeユーザーがチャットを直接開いた場合は、プラン選択を自動表示し、相談入力を無効にする。
- chat APIの403は英語エラーを表示せず、プラン選択の日本語案内へ切り替える。

## 2026-07-23 有料プランを値下げ

- 月間利用回数は変更せず、Liteを月額1,480円（税込）、Standardを月額4,800円（税込）、Enterpriseを月額9,800円（税込）へ変更する。
- 新規CheckoutはVercelに設定した各プランの `PRICE_ID_*_NEXT` を使用する。
- Webhookでは旧Price IDと新Price IDの両方を認識し、既存契約との互換性を維持する。
- 新料金の本番確認が完了するまでStripeの旧価格はアーカイブしない。

## 2026-07-22 無料体験を3回へ変更

- 登録不要の無料体験を1端末1回から1端末3回へ変更する。
- CookieとlocalStorageは完了フラグではなく使用回数を保存する。
- 端末DBは既存のUNIQUE制約を変更せず、1端末に3つの試行枠を持たせる。
- 旧仕様の1回目の履歴はそのまま引き継ぐ。

## 2026-07-22 OpenAIモデル提供終了への対応

- 品質評価の承認待ちより、回答機能の継続を優先する。
- OpenAI呼び出しを共通フォールバック処理へ集約する。
- モデル提供終了・不存在・アクセス不可の場合だけ、予備候補へ即時切替する。
- 切替時は機密情報を含めずVercelログへ記録する。
- 通常は公式の後継モデルを予備ENVへ明示する。
- 明示候補が全滅した非常時に限り、モデル一覧から厳格な一般向けGPT名だけを抽出し、実際の疎通成功を条件に自動選択する。
- snapshot、Codex、画像・音声等の用途違いモデルは自動選択から除外する。
