# 決定ログ

## 2026-07-24 Stripeの適用プラン判定を独立・自動テスト化

- Webhook内の複数契約から適用プランを選ぶ判定を、独立した純粋関数へ分離する。
- `active` と `trialing` の契約だけを対象とし、認識できるPrice IDのうち最上位プランを採用する。
- 現行・旧Price IDの両方を認識し、有効契約のPrice IDがすべて未知の場合は `free` へ変更せず未解決として処理を失敗させる。
- 同一プランが複数ある場合は契約期間終了時刻、作成時刻の順で適用対象を決める。
- Stripe、DB、UI、ENVの仕様は変更しない。

## 2026-07-23 全ルートへ基本セキュリティヘッダを追加

- 全ルートへクリックジャッキング、MIME誤判定、参照元情報の過剰送信を抑止するヘッダを付与する。
- カメラ、マイク、位置情報、ブラウザの決済機能は許可しない。
- HSTSは本番環境だけ有効にし、ローカル開発では付与しない。
- 既存のMeta Pixel、Supabase、Stripe通信を壊さないため、全面的なCSP導入は別工程とする。

## 2026-07-23 プラン回数を共通定義へ統一

- `free / Lite / Standard / Enterprise` の月間利用回数を `app/lib1/planMaster.ts` の0 / 5 / 30 / 100回へ統一する。
- 管理画面から新規同期した `free` ユーザーは `monthly_quota=0` で作成する。
- 管理画面のプラン変更APIと有料チャットAPIは、個別の回数定義を持たず共通プラン定義を参照する。
- 既存の `free` ユーザーは、再実行可能なデータ更新SQLで `users.monthly_quota` と `usage.limit_talks` を0へ統一する。
- 登録不要の無料体験3回は `free` ユーザーの月間枠とは別に扱い、変更しない。

## 2026-07-23 middlewareをproxyへ移行

- Next.js 16のファイル規約に合わせ、ルート直下の `middleware.ts` を `proxy.ts` へ変更する。
- 公開関数名は `middleware` から `proxy` へ変更する。
- `config.matcher`、メンテナンスの `off|soft|hard`、Supabase SSRセッション同期、Cookie引継ぎ、allowlistは変更しない。
- `middleware.ts` は残さず、ビルド時の非推奨警告を解消する。

## 2026-07-23 有料チャットのAI生成前に回数上限を確認

- AI回答の生成前にJST当月の `usage.used_talks` を確認する。
- 上限到達済みの場合は429を返し、OpenAI呼び出しを開始しない。
- 無制限対象ユーザーは事前上限判定をスキップする。
- 利用数の確認に失敗した場合は、費用だけが発生する状態を避けるためAI回答を生成しない。
- 正式な回数消費と同時実行時の最終判定は、既存の `consume_talk_v2` を維持する。

## 2026-07-23 Stripe Webhookを失敗後に再実行可能化

- Webhookイベントを `processing`、`processed`、`failed` で管理する。
- イベント受信時点ではなく、users・usage等の更新が正常完了した時だけ `processed` にする。
- 途中失敗は `failed` とエラー概要を記録し、Stripe再送時に再実行する。
- 同一イベントの同時処理は避け、5分以上停止した `processing` は再取得可能にする。

## 2026-07-23 デモ回答の締めすぎを緩和

- デモ回答の表示上限を750文字から1,200文字へ変更する。
- 「要点2件・注意1件」の固定をやめ、要点最大4件・注意最大2件まで表示する。
- 上限超過時は会社別の確認質問を先に確保し、本文側を完結文で調整する。
- 明確な税務質問でも、デモ回答の最後には結論が動く会社別の確認質問を1〜3行必ず表示する。
- 金額相談では提示額に正面から反応し、有利に整理できる可能性と成立条件まで無料で示す。ただし、無条件の肯定や未提示の数値レンジの創作はしない。

## 2026-07-23 デモ回答の途中切れ防止と信頼情報の写真変更

- デモ回答の箇条書きが途中で改行された場合は、続きの文を同じ項目として結合する。
- 読点や接続助詞で終わる不完全な箇条書きは表示しない。
- 750文字のデモ出力上限を超える場合は、原則として直前の完結した文で表示を終える。
- 無料体験直前の信頼情報には、ヘッダーとは別の申込用顔写真を使用する。

## 2026-07-22 OpenAIモデル提供終了への対応

- 品質評価の承認待ちより、回答機能の継続を優先する。
- OpenAI呼び出しを共通フォールバック処理へ集約する。
- モデル提供終了・不存在・アクセス不可の場合だけ、予備候補へ即時切替する。
- 切替時は機密情報を含めずVercelログへ記録する。
- 通常は公式の後継モデルを予備ENVへ明示する。
- 明示候補が全滅した非常時に限り、モデル一覧から厳格な一般向けGPT名だけを抽出し、実際の疎通成功を条件に自動選択する。
- snapshot、Codex、画像・音声等の用途違いモデルは自動選択から除外する。
