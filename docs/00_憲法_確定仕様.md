# さじかげん｜確定仕様

## 有料プラン

| プラン | 月額（税込） | 月間利用回数 |
| --- | ---: | ---: |
| Lite | 1,480円 | 5回 |
| Standard | 4,800円 | 30回 |
| Enterprise | 9,800円 | 100回 |

- 新規Checkoutは `PRICE_ID_LITE_NEXT`、`PRICE_ID_STANDARD_NEXT`、`PRICE_ID_ENTERPRISE_NEXT` を使用する。
- Webhookは切替前後のPrice IDをいずれも正しいプランへ判定する。

## 無料体験

- 登録不要の無料体験は1端末につき3回までとする。
- Cookie、localStorage、端末識別子の3層で使用回数を制限する。
- 旧仕様で既に1回使った端末は、その履歴を1回目として引き継ぎ、残り2回とする。
- 4回目以降は回答生成せず、プラン確認へ案内する。
- 無料体験の直後に、出張日当2万円を題材とした相談例・回答例を常時表示する。
- 回答例は可能性だけで断定せず、金額の妥当性、役員・従業員間のバランス、出張実態、旅費規程等の確認が必要であることを示す。
- 回答例のCTA「自社の場合を相談してみる」から無料体験の入力欄へ戻し、入力欄へフォーカスする。
- 無料体験の直前に、野口税理士の顔写真、資格・肩書き、法人税務・税務調査対応の実務経験を簡潔に表示する。
- 無料回答が正常に表示された直後に、その相談について有料版で具体化できる内容を表示する。
- 有料版の具体化内容は、会社の金額・運用条件に沿った線引き、必要書類、税務調査での想定質問と説明方法、顧問税理士への質問文とする。
- 回答後CTAは「この相談の続きを整理する」とし、プラン選択を開く。

## 新規登録後の申込導線

- プラン指定なしで新規登録した場合、メール認証後はチャットではなく、ログイン済み状態でプラン選択へ遷移する。
- 未契約のfreeユーザーがチャットを直接開いた場合は、入力・送信を無効にしてプラン選択を自動表示する。
- 未契約状態でチャットAPIが拒否した場合は、英語のエラーを表示せず、プラン選択を案内する。

## OpenAIモデル継続運用

- 最優先は、モデルの提供終了による回答機能停止を避けること。
- 通常時は用途別の指定モデルを使う。
- 指定モデルが提供終了・存在しない・利用権限がない場合に限り、設定済み候補へ自動で切り替えて同じ処理を再試行する。
- 認証エラー、レート制限、入力不備、OpenAI全体障害はモデル切替の対象にしない。
- 切替は承認待ちにせず即時実行し、Vercelログへモデル名と用途を残す。質問本文、回答、APIキーはログへ出さない。
- 候補の優先順は用途別ENV、共通ENV、コード内の緊急候補とする。
- 明示候補がすべて使えない時だけ、APIで現在利用できるモデル一覧を取得し、一般向けGPTの厳格な名前規則に合う新しい候補から疎通確認する。
- snapshot、Codex、画像・音声等の用途違いモデルは自動選択しない。
- OpenAIの提供終了告知とメールも定期確認し、後継モデルをENV候補の先頭へ追加する。自動選択は更新忘れ時の最後の保険とする。
